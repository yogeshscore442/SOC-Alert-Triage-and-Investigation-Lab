# Security Log Sources & Event Telemetry Reference

## 1. Windows Security Event Log (`WinEventLog:Security`)

Windows Security Event Logs are generated by the Local Security Authority Subsystem Service (`lsass.exe`). Auditing policies must be explicitly enabled via `secpol.msc` or Group Policy under *Advanced Audit Policy Configuration -> Audit Policies -> Logon/Logoff*.

---

### Event ID 4625: An Account Failed to Log On
- **Channel:** Security
- **Description:** Generated whenever a logon attempt is rejected by the system.
- **Key Fields:**
  - `TargetUserName`: The user account that attempted to authenticate.
  - `WorkstationName`: NetBIOS or DNS name of the client machine.
  - `IpAddress`: IPv4/IPv6 source address of the incoming connection (`-` if local console).
  - `LogonType`: The mechanism used to attempt access (see Logon Type Table).
  - `Status`: High-level NTSTATUS code (commonly `0xC000006D` for logon failure).
  - `SubStatus`: Detailed technical failure code:
    - `0xC0000064`: `STATUS_NO_SUCH_USER` — Account name does not exist. Indicates username enumeration or brute-force against unknown accounts.
    - `0xC000006A`: `STATUS_WRONG_PASSWORD` — Account name is valid, but the provided secret/password was incorrect. Indicates credential guessing or password spraying against valid accounts.
    - `0xC0000234`: `STATUS_ACCOUNT_LOCKED_OUT` — Account has exceeded the lockout threshold.
    - `0xC0000072`: `STATUS_ACCOUNT_DISABLED` — Authentication attempted against an inactive account.

---

### Event ID 4624: An Account Was Successfully Logged On
- **Channel:** Security
- **Description:** Generated when a user session is authenticated and granted a security token.
- **Key Fields:**
  - `TargetUserName`: The authenticated user name.
  - `TargetUserSid`: Windows Security Identifier of the user.
  - `TargetLogonId`: Unique hexadecimal session identifier assigned by LSA (e.g., `0x14A28F`). **This is the primary correlation key linking Windows authentications to Sysmon process creations.**
  - `LogonType`: Numerical code identifying the authentication method.
  - `IpAddress` & `IpPort`: Remote network coordinates of the authenticating machine.

---

### Windows Logon Types Reference

| Logon Type | Name | Practical Description | SOC Investigation Context |
| :--- | :--- | :--- | :--- |
| **2** | Interactive | Local console logon (Keyboard/Monitor). | Physical access or local VM console access. |
| **3** | Network | Access via SMB, RPC, or network shares. | Normal file shares, or lateral movement (PsExec, WMI, Impacket). |
| **4** | Batch | Scheduled task execution. | Task scheduler persistence or service automation. |
| **5** | Service | Windows service starting under its own credentials. | Background daemon or malicious service persistence. |
| **7** | Unlock | Unlocking an already authenticated workstation. | Physical user returning to screen. |
| **10** | RemoteInteractive | Remote Desktop Services (RDP). | Remote administrative access, GUI lateral movement. |

## 2. Microsoft Sysmon (`Microsoft-Windows-Sysmon/Operational`)

System Monitor (Sysmon) is a Windows system service and device driver that remains resident across system reboots to monitor and log system activity to the Windows event log.

---

### Event ID 1: Process Creation
- **Channel:** Microsoft-Windows-Sysmon/Operational
- **Description:** Logs process initiation with rich contextual metadata, including full command lines and cryptographic hashes.
- **Key Fields:**
  - `ProcessId`: PID assigned to the newly spawned binary.
  - `Image`: Complete filesystem path of the executable.
  - `CommandLine`: Exact string and arguments passed to the binary.
  - `CurrentDirectory`: Working path from which the command was invoked.
  - `User`: Account context executing the process.
  - `LogonId`: LSA session identifier matching `TargetLogonId` in Event 4624.
  - `ParentProcessId`: PID of the spawning process.
  - `ParentImage`: Path of the binary that spawned the child.
  - `Hashes`: Cryptographic signatures (MD5, SHA256) enabling threat intelligence and VirusTotal lookups.

---

### Event ID 3: Network Connection
- **Channel:** Microsoft-Windows-Sysmon/Operational
- **Description:** Logs outbound and inbound TCP/UDP socket connections initiated by host processes.
- **Key Fields:**
  - `ProcessId`: PID of the executable opening the socket.
  - `Image`: Path of the binary establishing the network connection.
  - `SourceIp` & `SourcePort`: Local host socket parameters.
  - `DestinationIp` & `DestinationPort`: Remote destination coordinates.
  - `DestinationHostname`: Resolved DNS name (if enabled in Sysmon configuration).

---

## 3. PowerShell Operational Logging

- **Event ID 4104 (Script Block Logging):** Captures complete blocks of executed PowerShell code, including de-obfuscated dynamic code generated at runtime via `Invoke-Expression` or `-EncodedCommand`.
- **Event ID 4103 (Module Logging):** Records pipeline execution details and modules loaded by PowerShell.
- **Telemetry Gap:** If Script Block Logging is not enabled via Group Policy, analysts can only see what was passed on the raw command line in Sysmon Event 1, missing file-based script contents or secondary payloads.
